# ממלכת המתמטיקה של אביב 👑

אפליקציית לימוד משחקית (בסגנון Duolingo) שמכינה את **המלכה אביב** למבחן במתמטיקה בכיתה ח':
משפט פיתגורס, יחס, פרופורציה, קנה מידה ושאלות משולבות.

**האפליקציה באוויר:** https://arielnevo.github.io/aviv-math-kingdom/
(בטלפון: "הוספה למסך הבית" — האפליקציה עובדת גם בלי אינטרנט.)

## מה יש בפנים
- **מפת הממלכה:** 5 יחידות ("טירות"), בכל אחת שיעורון, 4–6 שיעורים ובוס.
- **3 רמות קושי** (נסיכה 🌸 / מלכה 👑 / קיסרית 💎) ומצב **אדפטיבי**: 4 נכונות ברצף מעלות רמה, 3 טעויות בשיעור מורידות בעדינות.
- **8 סוגי שאלות:** הקלדת מספר (כולל `5√2`, `√50`, `5*sqrt(2)`), בחירה מרובה, נכון/לא נכון, יחס (`2:3`), מצאי את הטעות, התאמה, סידור שלבי פתרון בגרירה, והשלמת צעד חסר.
- **29 מחוללי שאלות** שמייצרים תרגול בלי סוף, לצד 127 שאלות מהבנק המאומת.
- אחרי כל טעות: **פתרון מלא צעד-אחר-צעד** וכפתור "הבנתי, נסי שוב דומה".
- **תרגול טעויות** עם חזרה במרווחים (אחרי יום, 3 ימים ושבוע), **מבחן מדומה** של 30 דקות עם פירוט לפי נושא, **סרטוני הסבר** קצרים, תגים, XP, רצף ימים ולבבות.

## הרצה מקומית
```bash
npm install
npm run dev      # http://localhost:5173
npm test         # כל הבדיקות (מחוללים, בנק השאלות, שיעורים)
npm run build    # בנייה לפרסום
```
כל push ל-`main` מריץ את הבדיקות ומפרסם ל-GitHub Pages אוטומטית (`.github/workflows/deploy.yml`).

## הוספת שאלות לבנק
הבנק נמצא ב-`src/data/questionBank.json`.
1. מוסיפים שאלה ל-`questions` (או ל-`wordProblems` לשאלה משולבת) עם `id` ייחודי, `topics`, `difficulty` (1–3), `type`, `text`, `answer`, `hint` ו-`solutionSteps`.
   - `numeric`: אפשר להוסיף `exact` (למשל `"5√2"`), `unit` ו-`tolerance`.
   - `text`: רשימת `acceptedAnswers` (למשל `["2:3", "2/3"]`).
   - `mcq` / `find_error`: ארבע `options`, ו-`answer` חייב להיות אחת מהן.
2. כדי שהשאלה תופיע בשיעור מסוים, מוסיפים את ה-`id` ל-`staticIds` של השיעור ב-`src/lib/curriculum.ts`.
3. מריצים `npm test`. הבדיקה ב-`tests/bank.test.ts` מוודאת שהמבנה תקין ושהתשובה מתקבלת.

## הוספת מחולל שאלות
1. ב-`src/lib/generators.ts` כותבים אובייקט `Generator` עם `id`, `topic`, `levels` ופונקציה `make(level, rng)` שמחזירה שאלה (כולל `params` עם הנתונים הגולמיים).
2. מוסיפים אותו למערך `GENERATORS` ולשיעור המתאים ב-`curriculum.ts`.
3. ב-`tests/generators.test.ts` מוסיפים **אורקל** — חישוב עצמאי של התשובה מתוך `params`. הבדיקה מריצה 300 שאלות לכל רמה ומוודאת שהתשובה נכונה מתמטית. **אסור שתופיע שאלה עם תשובה שגויה.**

## החלפת התמונה
מחליפים את `public/avatar/aviv.jpg` (ריבוע, 512×512 מומלץ) ואת `public/avatar/aviv-hero.jpg` (תמונה רחבה לפרופיל). אם הקובץ חסר, מוצג אווטאר מצויר.

## שינוי רמות
שמות הרמות, האימוג'י והתיאורים נמצאים ב-`meta.difficultyLevels` בבנק. ה-XP לכל רמה (10 / 15 / 25) מוגדר ב-`XP_BY_LEVEL` ב-`src/lib/store.ts`.

## סרטונים
סרטוני ההסבר נבנים בפרויקט Remotion שבתיקייה `video/` ונשמרים ב-`public/videos/<id>.mp4`. הרשימה ב-`src/data/videos.ts`.

## איורים
האיורים (הטירות, המפה והכתר) נוצרו ב-ChatGPT ונשמרו ב-`public/art/`. כל השרטוטים המתמטיים, פיתי הינשופה והאנימציות הם SVG מקורי.
